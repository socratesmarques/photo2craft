# Referências fixas

Coloque aqui JPG/PNG/WEBP seus: casa, igreja, carro, castelo, personagem e objeto comum.
Use sempre os mesmos arquivos para comparar versões. A primeira imagem precisa mostrar bem o assunto.
Não há fotos de terceiros incluídas. O benchmark registra SHA-256, opções, modelo, versão, dimensões,
tempos, pontuação (ou null) e salva referência, render, JSON e painel HTML por execução.
Confira manualmente forma, proporções e partes reconhecíveis. A nota não substitui essa avaliação.
